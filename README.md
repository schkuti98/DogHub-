DogHub
DogHub ist mein Abschlussprojekt für den Diplomlehrgang Software Developer JavaScript und Node.js am WIFI Wien.
Die Idee dazu kommt aus meiner Erfahrung als Hundetrainer. 
Ich wollte eine Anwendung entwickeln, mit der sich Hunde und ihr Training übersichtlich verwalten lassen.
Nach der Registrierung und Anmeldung können Hunde angelegt, bearbeitet und gelöscht werden. 
Übungen und Tricks, Trainingsfortschritte und Notizen bilden den weiteren Schwerpunkt der Anwendung. 
So sollen Informationen zum Training an einem Ort gesammelt werden, damit sich auch später nachvollziehen lässt, woran mit einem Hund gearbeitet wurde.

Für die Umsetzung verwende ich HTML, CSS und JavaScript sowie Node.js mit Express im Backend. 
Die Seiten werden mit EJS aufgebaut. 
Die Daten werden in MongoDB gespeichert, die Datenbank läuft über MongoDB Atlas.
